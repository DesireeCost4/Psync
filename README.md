# Psync - Sistema de Gestão Multidisciplinar

O **Psync** é uma plataforma desenvolvida para simplificar a gestão de atendimentos, cadastros e acompanhamento de clientes para profissionais autônomos e clínicas (como psicologia, odontologia e advocacia).

---

##  Sobre o Projeto

Este é um projeto pessoal desenvolvido de forma paralela à minha formação acadêmica nos cursos de **Técnico em Informática (IFPB)** e **Análise e Desenvolvimento de Sistemas (Estácio)**, integrando também conceitos práticos aplicados em **Redes/Telemática**. 

O objetivo do projeto é consolidar boas práticas de arquitetura de software, desenvolvimento full-stack e entrega contínua.

---

##  Funcionalidades Atuais

- **CRUD Completo de Clientes Finais:**
  - Cadastrar, listar, editar e remover pacientes/clientes vinculados ao profissional.
  - Feedbacks visuais de sucesso/erro e confirmação de exclusão.
- **Painel Dinâmico (Dashboard):**
  - Métrica de total de clientes cadastrados.
  - Alternância rápida entre diferentes nichos de négocio.
- **Interface Responsiva:**
  - Desenvolvida com **Bootstrap 5** em Dark Mode e integração com **Thymeleaf**.
